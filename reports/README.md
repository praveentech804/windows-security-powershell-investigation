# Investigation Reports

Document actual observations from Splunk searches here.

For each observation, record:
- Search/query used
- Time range
- Relevant event timestamps and IDs
- Host and fields actually present in the events
- Evidence observed
- Analyst interpretation and uncertainty
- Recommended follow-up checks

Do not label an event as a confirmed attack without supporting evidence.
Do not add findings or counts that have not been verified in Splunk.
